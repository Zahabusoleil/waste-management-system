About EcoTrack

EcoTrack is a web-based waste management and collection tracking platform built to solve the challenge of uncoordinated waste reporting in urban and peri-urban communities across Uganda.

Bugema University — Excellence in Service EcoTrack is an academic software engineering project developed at Bugema University, Kampala, Uganda.
Our Mission

Why EcoTrack Exists

Urban communities face a persistent challenge: waste accumulates faster than it is collected because reporting is fragmented, assignments are manual, and progress is invisible to everyone involved.

EcoTrack closes that gap by giving residents a simple digital reporting tool, administrators a central management dashboard, and collectors a structured task workflow — creating accountability at every step.

Transparent lifecycle from report submission to completion
Role-based access ensuring each user sees only what they need
Photo evidence upload for accurate waste classification
Audit logs for every administrative and collector action

Our Vision

A Uganda where every waste report is acknowledged, every collection is tracked, and every community has the digital tools to hold waste management accountable.

Who Uses EcoTrack

Three Roles, One Platform

Resident

Community member / Reporter
Register and manage a personal account
Submit waste reports with category, location and description
Upload a photo (JPEG, PNG or WebP, up to 5 MB)
Track report status from Pending to Completed
Edit or delete reports while Pending or Rejected

Administrator

System manager / Decision maker
Protected dashboard with live statistics
Search, filter, edit, activate or delete users
Create and manage collector accounts
Approve or reject pending waste reports
Reset user passwords and notify via WhatsApp

Collector

Field operative / Task executor
Log in with an administrator-provisioned account
View assigned collection tasks and report details
Start, progress, or block tasks with a reason
Mark tasks complete with notes
Access only tasks assigned to their own account

Technology

Built on a Proven Stack

N

Node.js & Express

RESTful API with structured routes, controllers, validators and middleware.

M

MongoDB & Mongoose

Document database with typed schemas, indexed queries and ObjectId references.

J

JWT & Secure Cookies

HttpOnly SameSite cookies, 7-day expiry, rate-limited login and CSRF checks.

H

HTML5 / CSS3 / JS

Vanilla frontend — no framework. Responsive, accessible interface.

Security

Security by Design

Password Hashing

All passwords hashed with bcrypt cost factor 10. Plain-text never stored.

Role-Based Access Control

Every API route protected by auth and role middleware independently of the UI.

Input Validation

All request bodies validated server-side with express-validator before DB storage.

Rate Limiting

Login limited to 10 attempts per 15 min. Reset requests limited to 5 per 15 min.

CSRF Protection

Cross-site requests rejected using origin and Sec-Fetch-Site header checks.

Audit Logging

Every administrative action recorded in a tamper-evident audit log collection.
